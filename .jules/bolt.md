## 2024-05-18 - Vectorize NumPy Variance inside Loops
**Learning:** In code dealing with large multi-dimensional arrays like chromagrams or spectrograms in audio processing (`np.ndarray`), it's inefficient to repeatedly slice and process subsets like columns or frames inside a Python `for` loop (e.g., `chroma_var = np.var(chromagram[:, i])`). This is mainly due to the cost of repeatedly crossing the Python-to-C boundary and creating temporary array views within the loop.
**Action:** Vectorize array statistics across the entire axis *before* the loop. In this case, `chroma_vars = np.var(chromagram, axis=0)` reduces loop complexity from performing $O(M)$ work $N$ times with heavy scalar overhead, to doing a single fast C-level operation, followed by an $O(1)$ array lookup `chroma_var = chroma_vars[i]` inside the loop, saving massive amounts of compute time (measured ~14x speedup).
