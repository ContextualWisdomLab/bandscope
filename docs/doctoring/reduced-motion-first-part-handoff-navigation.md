# Reduced-motion first part-handoff navigation

When `prefers-reduced-motion: reduce` matches, `FirstPartHandoffCallout` scrolls the renderer-owned song-structure section with `behavior: "auto"`. Otherwise it uses `behavior: "smooth"`.

Open still names the giving part, receiving part, labeled section, and time. Analysis `section.id` is never DOM-ID authority. This map next-action is distinct from the labeled `handoff` form (#937) and the Part Handoff Map visualization (#850).
